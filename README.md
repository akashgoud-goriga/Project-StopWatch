# Project-StopWatch
# ⏱️ Stopwatch Web Application

A simple and interactive **Stopwatch Web Application** built using HTML, CSS, and JavaScript. This project was created as part of my JavaScript learning journey to understand DOM manipulation, event handling, and time-based functions in JavaScript.

## 🚀 Features

- **Start:** Starts the stopwatch and begins counting time.
- **Stop:** Pauses the stopwatch at the current time.
- **Reset:** Resets the stopwatch back to zero.
- **Hours:** Displays elapsed hours.
- **Minutes:** Displays elapsed minutes.
- **Seconds:** Displays elapsed seconds.
- **Milliseconds:** Displays elapsed milliseconds.
- **Responsive UI:** Simple and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the stopwatch.
- **CSS3** – For styling and designing the user interface.
- **JavaScript** – For implementing stopwatch functionality and time calculations.
